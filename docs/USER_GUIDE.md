# 使用指南

## 初始化

首次打开系统时，页面会要求创建管理员。管理员创建完成后，系统关闭公开注册入口；后续成员账号由管理员在“账号与权限”中创建。

建议首位管理员立即完成：

1. 修改显示名称和密码。
2. 创建团队需要的品牌与产品线。
3. 创建资料分类和 SOP 分类。
4. 创建编辑人员与普通用户，并分配最小必要权限。
5. 完成一次备份并验证备份目录。

## 角色与权限

- 管理员：管理成员、目录、组织待办、审计记录、回收站和附件清理。
- 编辑人员：在被授权的品牌/产品范围内维护内容。
- 普通用户：查看有权访问的内容并管理个人待办。

品牌授权代表该品牌下全部产品；也可以只勾选具体产品。权限判断在服务端执行，前端隐藏不是唯一保护措施。

## 知识文档

“资料与制度”和“其它资料”用于通用文档；“品牌/产品 SOP”按产品组织操作文档。

编辑器支持 Markdown、表格、代码块、Mermaid、公式、图片和附件。编辑文章时可以新建或选择分类，设置草稿、已发布或已归档状态，上传或替换附件，设置目录图标，并查看版本记录。

删除文档后会进入回收站。清理附件前先检查引用，避免删除仍被有效文档使用的文件。

## 术语、模板与待办

开源副本不预置术语和业务模板。管理员或编辑人员可自行创建分类，再录入术语或模板。

个人待办支持临时事项与日/周/月周期规则。组织待办由管理员创建，可下发给全部成员或指定成员，并查看完成情况。

## 日常维护

- 每日或每周执行在线备份。
- 定期把备份复制到另一块磁盘或另一台受控设备。
- 定期检查回收站、孤立附件和审计记录。
- 成员离开团队时立即停用或删除账号并复核内容权限。
- 升级前先备份数据库与附件，并在测试环境验证新版本。
